Required Firestore architecture:
- Store tasks under:
  users/{uid}/tasks/{taskId}

- id
- title
- description
- dueDate
- dueTime
- priority
- status/completed state
- category
- labels/tags
- createdAt
- updatedAt
- any other existing Task fields already required by the current components

Required behavior:
- Load the authenticated user’s tasks from Firestore.
- Use onSnapshot for real-time updates.
- Creating a task writes it to Firestore.
- Editing a task updates Firestore.
- Completing or reopening a task updates Firestore.
- Deleting a task removes it from Firestore.
- Changes must appear automatically in another browser or device signed in with the same account.
- Each user may only access their own tasks.

Migration:

- Do not automatically upload demo/mock tasks into Firestore.

  users/{uid}/tasks/{taskId}
