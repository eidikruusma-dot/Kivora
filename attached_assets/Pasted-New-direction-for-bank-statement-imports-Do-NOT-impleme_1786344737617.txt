We are changing the product architecture for bank statement imports.

Product decision

Bank statement importing should no longer depend on the AI chat workflow.

The Money module should have its own explicit action:

“Impordi pangaväljavõte” / “Import bank statement”

Desired user flow:

Money module → Import bank statement → select PDF → extract transactions → validate → show review card → user confirms → import transactions into Money

There must be exactly one final user confirmation before writing transactions.

Important separation

AI chat and Money import are now separate use cases.

AI chat

PDFs remain usable as normal documents.
The user can ask questions about a bank statement like any other PDF.
AI chat does NOT need to trigger Money imports.

Money module

Explicit “Import bank statement” action.
Because the user explicitly selected bank-statement import, this flow must NOT depend on looksLikeBankStatement() to decide whether to attempt extraction.
The specialized bank extractor should validate whether the selected document is actually a usable bank statement.
If it is not a bank statement, show a clear error and do not import anything.

Therefore do NOT assume that moving the existing extractor into the Money module solves extraction reliability.
