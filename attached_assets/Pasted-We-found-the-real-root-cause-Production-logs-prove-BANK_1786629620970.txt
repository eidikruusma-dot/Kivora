We found the real root cause.

Production logs prove:

[BANK IMPORT BEFORE AI] { isBuffer: true, bufferLength: 0 }
[BANK IMPORT AI ENTRY]  { isBuffer: true, bufferLength: 0 }

But the browser upload is:

size: 86660
type: application/pdf

The buffer is becoming zero-length BEFORE the AI fallback.

PDF.js documentation states that TypedArray data passed to getDocument()
may be transferred to the worker thread, taking ownership of the TypedArray.

Therefore the structural PDF parser must NOT consume the same Buffer instance
that is later needed by the AI fallback.
